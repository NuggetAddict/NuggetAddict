## 🚀 Projects & Experiments

### 🎵 Automated Music Library Pipeline
My workflow for turning Spotify playlists into a clean, local **FLAC** library for my FiiO M21, built around **spotDL**, **yt-dlp** and Python.

- YouTube Music as first source, regular YouTube as fallback
- Batch downloads from text files, plus TXT / M3U / CSV playlist metadata
- Finding missing tracks and replacement links
- Output organised automatically:

```text
Playlists/
└── {playlist}/
    └── {artist}/
        └── {album}/
            └── {title}
```

### 🤖 NavBot EN-01 *(concept)*
A small interactive robot companion inspired by BD-1: ESP32 controller, movable head, MagSafe-style base, simple movements and beeps, and possible ChatGPT integration.

### 🏠 Smart Home AI *(exploring)*
Researching which AI models fit best with **Home Assistant**, comparing local inference with cloud AI for routines and device integration.

### ⌚ Smartwatch → Calendar Device *(exploring)*
Turning an Android smartwatch into a dedicated, minimal calendar computer using ADB, Device Owner / Lock Task Mode and an alternative launcher.

### 🔊 KEF 303 Bluetooth Speaker *(concept)*
Combining a KEF 303 Series 2 with Bluetooth audio and a DC-powered amplifier, with a futuristic orange sci-fi look.
